

# 🎈 Balloon Decoration Service

A website for a balloon decoration business where customers can explore decoration designs, view packages, and submit booking enquiries for special occasions.

## ✨ Features

### 🎉 Decoration Services
- Birthday Decorations
- Anniversary Decorations
- Baby Shower Decorations
- Wedding and Engagement Decorations
- Balloon Arches and Backdrops
- Room Decorations
- Custom Event Decorations

### 👤 Customer Features
- Browse decoration designs and themes
- View decoration packages
- Check package details and pricing
- Submit booking enquiries
- Provide event date and location
- Request customized decorations

### 🔐 Admin Features (If Implemented)
- Add, update, and delete decoration packages
- Manage customer enquiries
- Manage bookings
- Update package prices and availability
